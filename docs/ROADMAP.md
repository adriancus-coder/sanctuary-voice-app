# Roadmap

Deferred work and intended direction. Not commitments — a place to record decisions
so later commits have context.

## Quick text → "Anunț" items in the event program

Today, "quick text" (pinned announcements: welcome, prayer, verses) is a section of
**Ecran principal** — a sender + a reusable library, pushed straight to the
projector as pinned text (`SV-ADMIN-QUICKTEXT-ECRAN`).

**Later:** fold quick texts into the **event program** as first-class **"Anunț"
(announcement) items**, the way songs already sit in the program — like worship-app.
Each announcement becomes a program entry you can order, schedule and send in
sequence alongside songs, instead of a standalone pinned-text push. The current
pinned-text library becomes the source of reusable announcement bodies. This keeps
the operator working from one ordered program during the service rather than
switching between a song list and a separate quick-text panel.
